
 ByteBuddy Academy - Learning Platform for Kids
 ----------------------------------------------------

ByteBuddy Academy is a web application designed to teach children programming skills. The platform offers a variety of courses, tutor interactions, and an easy-to-use dashboard for parents and administrators to manage children's learning journeys. It also allows administrators to schedule classes and evaluate the progress of enrolled students.

-----------------
Project Overview
-------------------

This web application has been developed as part of the IT312 Web Applications Engineering course at King Saud University. The application serves as an educational platform for children to learn programming skills under the guidance of tutors, with support from parents and administrators.

-------------
Features
------------

### 1. Homepage
- Displays an overview of the website, including information about available courses, user feedback, and an easy-to-navigate interface.

### 2. Courses Page
- Course Listings: Shows all the available courses along with their descriptions, helping parents and children make informed choices.
  
### 3. Tutors Page
- Tutor Profiles: Lists all tutors, their specializations, and contact information.

### 4. Administrator Dashboard
- Admin Controls: Provides a comprehensive overview of all registered students, courses, and tutors.
- Schedule Management: Allows administrators to manage and assign weekly teaching schedules for tutors.

### 5. Parent Dashboard
- Child Management: Parents can view and manage their children's learning progress, enroll them in new courses, and evaluate the courses.
- Enrollment: Parents can register their children for available courses using filters like prerequisites or assigned tutors.

### 6. Registration
- Kid Registration: Parents can register their children by filling out a form with basic details, creating a personalized learning experience.

### 7. Course Enrollment
- Flexible Course Registration: Provides the ability to enroll children in courses based on filters such as course prerequisites and tutor assignments.

### 8. Course Evaluation
- Feedback System: Allows parents to provide feedback and rate courses, helping improve the quality of the courses offered.

 Competitive Analysis
 --------------------

The ByteBuddy Academy platform draws inspiration from existing educational websites like:
- Code.org
- BrightCHAMPS
- Scratch (MIT)
---------------------------
Comparison of Key Features:
---------------------------
- Navigation: All three competitor websites offer clear navigation, but Scratch provides a more kid-friendly interface.
- Efficiency: Sites like Code.org and Scratch allow users to test the platform without signing up, promoting ease of use.
- Content Delivery: ByteBuddy Academy includes key features found on competitors' sites, such as tutor details, course feedback, and programming resources for kids.

Installation and Setup
--------------------------

1. Clone the repository:
     git clone https://github.com/your-username/ByteBuddyAcademy.git
   
2. Navigate to the project directory:
     cd ByteBuddyAcademy
   
3. Install dependencies:
     npm install
   
4. Start the application:
     npm start
